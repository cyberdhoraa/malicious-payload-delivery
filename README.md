# CyberDhora Investigation Toolkit

CyberDhora is a specialized digital investigation toolkit designed for security researchers and investigators.

## Features
- APK malware delivery
- PDF exploitation
- Image payload injection
- YouTube-based attacks
- Custom branding and logo support

## Installation
1. Clone repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run application: `python3 payload_delivery.py`

## CyberDhora Branding
All components use CyberDhora's signature color scheme:
- Primary: #00eeff (Aqua)
- Secondary: #4a4a8a (Deep Blue)
- Background: #1a1a2e (Dark Blue)

## CyberDhora Security Protocol
All operations follow CyberDhora's secure communication standards.

## Requirements
- Python 3.x
- tkinter
- requests
- Pillow

## Customization
- Add custom logo: `cyberdhora_logo.png`
- Modify appearance in `payload_delivery.py`
